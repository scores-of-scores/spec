Maintaining this report

The data are YAML files in formats/: one file of features per category, plus sources, cases and fixtures. Run python3 tools/build.py: it validates every file against its schema, checks identifiers, source references and the links from the Principles rules, and rebuilds this page. Capability, evidence, subset and empirical-test status are separate fields. A cell counts as tested only when a fixture that covers it has a recorded result for that format. Filters do not treat a workaround as direct semantic support. Features marked rule-linked bear on a rule of the Transcription Principles; the rule IDs are shown under the feature name.
